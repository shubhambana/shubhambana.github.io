Projects & Platforms

Two machine learning projects, each with a live app and the code on GitHub.

Customer Churn Prediction

ML + Live App
Predicts which telecom customers are likely to leave, and why
  • IBM Telco data (7,043 customers, 26.5% churn). Removed leaking columns and built one Scikit-learn pipeline.
  • Compared 4 models, tuned 3 with GridSearchCV. Final Random Forest: F1 62.20%, recall 71.93%, ROC-AUC 85.09%.
  • SHAP waterfall plot inside the Streamlit app, plus a FastAPI endpoint and Dockerfile.
PythonScikit-learnSHAPStreamlitFastAPI

Built on a public sample dataset to practise the full workflow.

Heart Disease Risk Predictor

ML + Live App
Estimates heart disease risk from clinical inputs
  • Inputs include age, chest pain type, blood pressure, cholesterol and max heart rate (Kaggle / UCI dataset).
  • Cleaned and explored the data, compared Logistic Regression, SVM and Random Forest, and chose Random Forest.
  • Streamlit app returns a risk probability, and a FastAPI /predict endpoint serves other apps.
PythonScikit-learnStreamlitFastAPI

Educational project. Not a medical tool and not for diagnosing anyone.
